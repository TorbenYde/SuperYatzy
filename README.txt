SuperYatzy Online v22

Samme fungerende spil som v21.
Nyt officielt SuperYatzy-appikon baseret på det godkendte terning/hånd-motiv.
Ikoner:
- 192x192
- 512x512
- 512x512 maskable

Service worker-cache er versioneret til v22, så nye installationer henter de nye ikonfiler.

Behold v21 som backup, indtil ikonet er testet på telefon, Chromebook og iPhone.
